# Luxe & Ember — A Sensory Collage
> *Two Worlds. One Glass Door.*

[![Project Status: Active](https://img.shields.io/badge/Status-Premium%20Release-gold.svg)](#)
[![Tech Stack: Modern Web](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20JS-maroon.svg)](#)

Luxe & Ember is a high-end, editorial-grade web experience designed for a boutique café that transitions seamlessly between artisanal day-mode and cinematic nocturnal-mode. This project focuses on **Sensory Architecture**, combining fluid typography with a modular, collage-inspired layout to create a "digital sanctuary" for the modern guest.

---

## ✨ Key Features

### 🌓 Day-to-Dusk Transition
A revolutionary atmosphere toggle that transforms the entire site's DNA. From the bright, amber-tinted morning pour to the deep, sapphire-pulse of a nocturnal lounge.
- **Day Mode**: Focused, light-filled, and clean.
- **Night Mode**: Cinematic, high-contrast, and glowing.

### 📜 Editorial Typography & Layout
A "Sensory Collage" design language that eschews rigid grids for artistic balance.
- **Arched Framing**: Bespoke framing for food and beverage photography.
- **Dynamic Micro-animations**: Subtle entrance reveals and parallax spotlights that react to user intent.
- **Floating Narrative Cards**: Contextual "Sandwich" and "Ritual" cards that provide depth without clutter.

### ☕ Interactive Mixology
- **Build Your Drink**: A custom selection interface where guests can visualize their creation before ordering.
- **Ember Timeline**: A choreographed history of the brand from napkin sketch to sanctuary.

### 📱 Premium Mobile Experience
Zero-compromise responsiveness.
- **Sliding Drawer Menu**: A glassmorphism-based navigation drawer with staggered link reveals.
- **Fluid Layouts**: Re-engineered for narrow viewports using a vertical editorial stack.
- **Touch-Optimized**: High-precision tap targets for reservations and menu browsing.

---

## 🛠 Technology Stack

- **Core**: Semantic HTML5 & Modern ES6+ JavaScript.
- **Styling**: Vanilla CSS3 with a comprehensive design system (CSS Variables).
- **Interactions**: Intersection Observer API for scroll-based reveals.
- **Aesthetics**: Glassmorphism, Backdrop Blurs, and Radial Spotlights.
